# sistema-gestao-estoque-tapiocaria-da-duda
## Sobre o projeto

Sistema web desenvolvido como projeto acadêmico, com o objetivo de auxiliar a Tapiocaria da DUDA no controle de estoque e na organização das compras de ingredientes.

A solução busca facilitar o acompanhamento das quantidades disponíveis, o registro de compras e a consulta dos gastos com reposição de ingredientes.

## Objetivo do MVP

Desenvolver uma aplicação web responsiva, acessível por computador e celular, que permita:

- Cadastrar ingredientes e suas unidades de medida;
- Registrar compras com quantidade, data e valor;
- Atualizar as quantidades em estoque a partir das compras registradas;
- Consultar o histórico de compras;
- Acompanhar os gastos por período.
